# 一鍵精靈 OneClick Wizard

多帳號、多網站的一鍵開啟／登出工具。針對需要同時管理多個網站帳號、常態切換多組登入資訊的使用情境設計，透過 Chrome 分頁群組把相關網站整理在一起，並自動帶入帳號密碼，省去每次手動輸入的麻煩。

## 功能總覽

### 一鍵開啟
- 依「群組」或「全部」一次開啟多個網站，自動依設定分頁群組（Chrome Tab Groups），並套用群組名稱與顏色。
- 每個網站可設定**備用網址**：開啟時會從「主要網址＋備用網址」中隨機挑一個開啟，避免單一網址異常時卡住整組流程。

### 自動填入帳號密碼（一次性）
- 只有透過「一鍵開啟」建立的分頁才會被標記可自動填入，且每個分頁**只會生效一次**。
- 一般手動輸入網址、點擊連結、或原本就開著的分頁，即使網址與已設定的網站相符，也**不會**被自動填入帳密。
- 支援常見登入欄位（email／帳號／使用者名稱等各種常見命名方式），並具備動態表單的重試機制。

### 一鍵登出
- 預設清除該網站（含備用網址對應網域）的 Cookie 與網站資料（localStorage / IndexedDB / Cache 等）。
- 也可個別設定「自訂登出網址」與「登出按鈕 CSS 選擇器」，有設定時優先使用。

### 帳號與群組管理
- 新增／編輯／刪除單一網站，可設定名稱、網址、備用網址、帳密、所屬群組、登出設定。
- 批量貼上多個網址，一次解析並匯入。
- 群組可新增、重新命名、刪除、自訂顏色（對應 Chrome Tab Groups 支援的九種顏色）、摺疊／展開。
- 網站與群組皆可拖曳排序、跨群組搬移；**支援多選網站後一起拖曳搬移**。
- 網站列表支援勾選多選，可一次刪除多個網站。

### 預設帳號密碼
- 可設定一組「預設帳號密碼」。
- 任何「本身沒有填寫帳號密碼」的網站，會自動統一使用預設帳密登入，不需額外設定。
- 也可以透過「套用到所有網站」一鍵強制讓所有網站改用預設帳密（會覆蓋個別設定）。

### 介面與資料
- 4 種馬卡龍配色（蜜桃粉／薄荷綠／薰衣草紫／奶油檸檬）可即時切換並記住選擇。
- 獨立可調整大小的管理視窗（`chrome.windows.create`），會記住上次的大小與位置。
- 資料皆儲存在 `chrome.storage.local`，支援匯出／匯入 JSON 備份檔（合併或覆蓋模式）。

## 安全提醒

⚠️ 本工具將帳號密碼以**明文**儲存在瀏覽器本機（`chrome.storage.local`），僅存在於你自己的裝置上，未經任何伺服器傳輸。為了安全起見：
- 請勿在公用電腦或共用裝置上使用。
- 避免存放高風險帳號（如銀行、公司核心系統）的密碼。
- 建議定期使用「匯出」功能備份，並妥善保管備份檔案。

## 安裝方式

1. 下載oneclick-wizard.zip並解壓縮本專案資料夾。
2. 開啟 Chrome，前往 `chrome://extensions`。
3. 右上角開啟「開發人員模式」。
4. 點選「載入未封裝項目」，選擇解壓後的資料夾。
5. 點擊工具列上的一鍵精靈圖示，即會開啟管理視窗。

## 檔案結構

```
oneclick-wizard/
├── manifest.json     Manifest V3 設定
├── background.js     Service Worker：開窗、分頁分組、Cookie 清除、一次性自動填入標記
├── content.js         內容腳本：向 background 詢問並執行一次性自動填入
├── manager.html       管理視窗畫面（獨立可調整大小視窗）
├── manager.js         管理視窗邏輯：CRUD、拖曳、配色切換、匯出入
├── storage.js         共用資料存取模組（background / manager 皆會載入）
├── styles.css         介面樣式（馬卡龍配色 + 果凍感設計）
└── icons/             工具列與擴充功能圖示（Pac-Man 造型）
```

## 資料結構（`chrome.storage.local`）

```js
{
  settings: {
    palette: 'peach',                          // 目前配色：peach / mint / lavender / lemon
    defaultAccount: { username, password },     // 預設帳號密碼
    windowBounds: { width, height, left, top }  // 管理視窗大小與位置
  },
  groups: [
    { id, name, color, collapsed, order }
  ],
  sites: [
    {
      id, groupId, name, url,
      backupUrls: [],           // 備用網址清單
      username, password,
      useDefaultAccount,        // 是否強制套用預設帳密
      logoutUrl, logoutSelector,
      order
    }
  ]
}
```

## 測試建議

1. 新增群組 → 批量貼上幾個網址匯入 → 設定帳密（或留空測試預設帳密自動套用）。
2. 按「一鍵開啟」，確認分頁有依群組正確分組，且帳密有自動填入。
3. 手動另外開一個分頁輸入相同網址，確認**不會**自動填入（驗證一次性行為）。
4. 測試拖曳排序、多選刪除、多選跨群組搬移。
5. 切換配色、調整視窗大小後重開，確認設定與視窗大小有被記住。
6. 測試「一鍵登出」與匯出／匯入備份檔。
